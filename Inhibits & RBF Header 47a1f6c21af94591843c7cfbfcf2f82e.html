PyCubed Inhibits

There are 3 inhibit locations (2 high side, 1 low side) capable of disconnecting the battery. These are commonly used with foot switches, rail switches, old-school RBF pin, etc...

  • The screw terminal connectors allow interfacing with nearly any inhibit wiring scheme.

RBF Header

The RBF header allows you to BYPASS these inhibits. Allowing...

  • easy benchtop software development
  • charging of batteries after integration (inside deployer)
  • programming & verification after integration (inside deployer)

It's called the "RBF header" since you might want to pull the jumpers/cable before launch.

Jumper Matrix

PyCubed ships with two 0.1in header jumpers installed in the "Benchtop Testing - Without Battery" configuration (also pictured above).

This is the most common configuration for software development not requiring high RF power output.
